# 我的迷你城市 · 第一章可玩版 v0.1

独立于旧版单 HTML 原型的 TypeScript 城市模拟游戏。目标是先验证 **建设 → 服务 / 就业 → 财政结算 → 诊断 → 调整** 的完整操作循环，并让模拟规则可测试、可解释。

## 在线试玩与发布

部署目标：**https://zce-demo.github.io/mc/**

每次推送 `main`，GitHub Actions 会完成 TypeScript 构建、模拟回归、制作静态站点并部署至 GitHub Pages。

**首次启用必须由仓库管理员完成一次**：打开 [Settings → Pages](https://github.com/zce-demo/mc/settings/pages)，将 **Build and deployment → Source** 设为 **GitHub Actions**。随后在 Actions 中重新运行 *Deploy playable city to GitHub Pages*。GitHub App 的仓库内容写入权限并不等同于启用 Pages 的管理权限。

发布资源放在 `site/`（构建时生成，不加入 Git）。静态资源一律用相对路径，兼容项目子路径 `/mc/`。

## 快速开始

```bash
npm install
npm run dev
```

`npm run dev` 会先编译 TypeScript，再启动 Vite 开发服务器。若要用普通静态服务器启动，请先执行 `npm run build` 生成 `dist/`，再运行 `python3 -m http.server 5173` 并访问 `http://localhost:5173`。不要直接双击 `index.html`（浏览器 file:// 模块限制可能阻止加载）。

```bash
npm test
```

## 第一次游玩（第一章）

1. 地图中间有一格市中心道路。按住并拖动「道路」，再铺三格道路，任务卡会提示奖励。
2. 在道路旁建立 2 栋住宅及商店，准备居民与工作岗位。
3. 接入发电站和水塔，点击「过一天」，观察居民迁入。
4. 建学校、诊所提升服务满足率，使用「诊断」查看服务缺口。
5. 为小镇继续增加住房和合适的工作岗位，连续两天保持日常财政盈余，完成第一章。

屏幕左侧是始终可见的目标卡；右侧是可收起的工作区。道路支持连续拖铺，同一条路径算一次撤销。右键检查或切换「检查」可点选建筑，直接在工作区切换运营状态。新增自动 1× / 2× / 4× 速度与手动过一天。

保存会在建造或日结后自动写入本机浏览器，另可手动保存及导出 JSON。更换浏览器、设备或清除站点数据前请导出备份。

## v0.1 有什么

- 固定种子生成平地、森林、河、山地；地图横纵比一致，滚轮缩放、拖动画布。
- 永久整数世界坐标；按 6×6 地块从已有土地向四方向持续购买。
- 11 种可建造设施，包括道路、桥梁、隧道、住宅、商店、农场、学校、诊所、公园、发电站、水塔。
- 建造校验：土地归属、地形、道路连通、预算；私营建筑日常费用不直接进入市政账本。
- 居民容量、岗位匹配、水电供需、教育与医疗的容量及就近分配、税收与公共运营成本。
- 每日财政流水唯一来源；预测来自同一个纯报告计算。调整税率、运营模式；同一天 10 步撤销，连续道路绘制合并为一次操作。
- 自动保存（每 5 个游戏日）、手动保存、v0.1 JSON 导入/导出；城市日志与诊断面板。

## 操作

地图点击放置；空格+拖动地图；右键检查；滚轮缩放。`R` 道路、`I` 检查、`P` 暂停、`F` 回到中心，`Ctrl+Z` 撤销。普通点击检查学校、诊所或水电设施，可循环调整正常、低负荷、关闭。

游戏默认每 9 秒前进一天，可切换 1×、2×、4×，也可以点击「过一天」。起步先从 (0,0) 的虚拟中心路口延伸道路，然后建住房、商店和水电设施。

## 明确的第一版范围

**尚未实现**：v4.x 存档迁移、完整章节与限时事件、交通需求/车辆与红绿灯、分块存储和 IndexedDB，以及 React 浮层组件系统。当前采用简单 TypeScript + Canvas + DOM 工作区来打通可玩的内核；UI 目前并非计划中的最终 React 架构，后续可在不修改模拟模块的情况下替换。也尚未覆盖玩家 484 人老存档的性能回归。

## 设计准则

模拟核心位于 `src/sim`，不引入 DOM。内容定义在 `src/content`，Canvas 绘制在 `src/main.ts`；统一 `dispatch` 接口校验操作、记录事件；`nextDay` 单入口结算；`report` 返回财政和诊断数据。所有金额按整数处理。旧存档目前不会自动被转换，也绝不会被新版本覆盖。

已批准的 GDD 与架构基线参见 `docs/`。
